# FinancasSeguras

O sistema Finanças Seguras será seu maior aliado na hora de cuidar de seus gastos e receitas, fazendo o registro completo com histórico financeiro, totalmente customizavel, podendo escolher qual categoria de dados deseja ver.

E pensando nos usuarios fizemos um software totalmente segura contra ataques

Hardcoded SQL (usar ORM ou queries parametrizadas)
SQL Injection
Cross-Site Scripting (XSS)
Cross-Site Request Forgery (CSRF)
Mass Assignment
Session Hijacking
Outras vulnerabilidades relevantes (como validação de entrada, autenticação segura, etc.)
